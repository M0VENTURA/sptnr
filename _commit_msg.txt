fix(single): check corroborating sources after a primary confirm

The source table / Matched: line only showed sources checked before the
pipeline gave up after a Discogs/MusicBrainz confirm. Two early-stop gates
hid legitimate corroboration:

1. ISRC lookup ran only when not musicbrainz_confirmed - a track can be a
   single on one release while its recording's release-groups carry
   different primary types; the ISRC path (bounded to tracks that HAVE an
   ISRC, MB-cached) adds genuine cross-release corroboration. Now runs for
   every track with an ISRC.

2. Discogs-video corroboration ran only when neither Discogs nor MB
   confirmed (rate-limited Discogs call). Now configurable via
   single_detection.always_check_discogs_video (default False) - set it to
   also run after a primary confirm so a track that is both an MB single
   AND has a Discogs video shows full corroboration. Config page toggle +
   JS wiring added.

Adds regression tests + changelog.
