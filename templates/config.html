Search Filters
Manage keywords that trigger removal of parenthetical content during API searches
What are search filters? When searching external APIs (Spotify, MusicBrainz, Last.fm, etc), track titles often contain edition markers like (Remastered), (Radio Edit), etc. These filters remove parenthetical content for the same song, different cut (remasters, edits, versions).

Note: Live versions, remixes, acoustic versions, etc. are different recordings and should be searched with their parentheses intact for accurate matching.

Examples:
  • "Song (Remastered)" → "Song" (same song)
  • "Song (Radio Edit)" → "Song" (same song, radio cut)
  • "Song (Live)" → "Song (Live)" (different recording, keep parentheses)
  • "Song (Acoustic)" → "Song (Acoustic)" (different recording, keep parentheses)
Press Enter or click Add to add a new keyword
