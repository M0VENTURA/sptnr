{# Unified Hybrid Search Flyout — All / In Library / MusicBrainz ============================================================= Header-anchored overlay panel (slides down from the fixed navbar), included from base.html and available on every page. Backed by static/js/unified_search.js. Scope rules: - All : library + MusicBrainz releases merged into the artist-page discography buckets (ARTISTS, ALBUMS, COMPILATIONS, LIVE ALBUMS, EPS, SINGLES, TRACKS), year-sorted with local 🟢 results before external 🟡 (quick-queue) results - In Library: library results only (POST /api/search) - MusicBrainz: release search via the shared MB component internals (searchMusicBrainzReleases) with quick-queue buttons The release-type dropdown and the collapsible advanced filters (Artist / Album / Track / Year) map to the structured fields on POST /api/musicbrainz/search so precision queries don't hit the free-text Lucene path. Debounce: 50ms local scopes / 400ms MusicBrainz (set in unified_search.js). The container keeps the id ``unifiedSearchModal`` so the engine's element lookups stay unchanged; the Bootstrap modal shell was replaced by a position:fixed flyout anchored below the navbar. #}
